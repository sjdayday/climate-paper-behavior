New WUWT Feature - Scafetta's forecast -vs- the IPCC forecast - Watts Up With That?
I have a new feature page on WUWT that highlights the work of Nicola Scafetta and his solar-lunar cycle forecast model as it compares to the IPCC forecasts and global temperature reality using HadCRUT surface temperature data.

Working with Dr. Scafetta, we’ve created not only a dedicated reference page which will be updated monthly as new data arrives, but there’s also a sidebar widget suitable for placement on other blogs to link to the forecast page. Time will tell how well his forecast model holds up. So far it is already beating the pants off the highly upwards IPCC forecast model, but like any forecast model, isn’t perfect.
