# Pilot: public communications (Stage 2 pilot)

This folder holds the pilot work behind `sources/communication-behavior-protocol_v0.2.md` (v0.1 kept for history), run on the two pilot papers (LS11, FR11). Both are excluded from the confirmatory sample.

| File | What it is |
|---|---|
| `public-communications-inventory-LS11-FR11.md` | Author communications inventory, from 3 months before to 12 months after publication (compiled 2026-09-18; English filter plus two German items) |
| `pilot-exhibit-4_public-communications_LS11-FR11.md` | Index C applied to the communications: tier inheritance, drift, and the first statement of rules C-1…C-8 (renamed PC-1…PC-8 in the protocol). F&R11 totals revised 2026-09-25. |
| `translation-review/rahmstorf-DE_review-packet.md` | Prototype non-English review packet: German originals scored, with glosses, marker notes, translation-sensitivity flags and full translations. Source of the FR7b fidelity-error finding. |
| `pilot-exhibit-4_addendum-1_decisions-D2-D6.md` | Re-score under decisions D2–D6 (2026-09-26): comment-thread census (313 author replies) with exploratory claim scores, the census-vs-sample simulation, register (PC-9) and dyads, social media and transcription status, and a Stage 1 note on FR11 P3 |
| `sources/` | Verbatim text captures of every page read, with provenance headers; `MANIFEST.md` lists hashes and the items not captured. `sources/threads/` holds author replies from 10 comment threads (JSON, with its own manifest). |

Register and reply-claim data for all pilot papers (LS11, FR11, CN21) are in `../register/`.

**Order of reading.** Inventory, then Exhibit 4, then the review packet, then Addendum 1, then the protocol (v0.2).
